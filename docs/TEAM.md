> Якщо в команді 5 людей: додайте **DA-2** (навички: каталог, `extract_skills`, `parse_cv`) — тоді DA-1 береться за матчинг/зарплати/апгрейд.

## Правила паралельної роботи

1. **Contract-first.** Перші 30–40 хв: DA кладе `analytics/fixtures/*.json` + заглушки функцій (`analytics/*.py` повертають фікстури), WE-A — `models.py`, каркас Flask і `storage.py`. Далі всі працюють паралельно; заглушки поступово замінюються реальним кодом.
2. **Своя територія.** Кожен править лише свої файли (таблиця вище). Чужий файл — тільки після повідомлення власнику.
3. **Зміни контрактів** — спочатку в `docs/CONTRACTS.md`, потім у код, і ping у чат.
4. `git pull --rebase` перед роботою й перед кожним комітом; коміти малі, часті, **від різних людей**; ніяких force-push.
5. Одна команда запуску: `pip install -r requirements.txt && python -m analytics.build && python -m app.main`.
